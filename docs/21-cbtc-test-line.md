# 21 — 测试线：CBTC 移动闭塞 + 简单调度

> 这一份写的是**能先跑起来的最小 CBTC**，不是完整 CBTC。
> 目的：在只有一列车的试验线上，把「移动授权 → 速度限制 → 指令下发」这条链先接通，
> 等有多列车时能立刻看到真实的间隔控制。

---

## 1. CBTC 是什么（以及我们只做哪一段）

CBTC = 基于通信的列车控制。与固定闭塞的根本差别是：**闭塞分区不是物理的，而是随车移动的**。

标准分工：

| 角色 | 职责 | 在我们的实现里 |
|---|---|---|
| **ZC**（区域控制器） | 收集列车位置与区段占用，计算每列车的**移动授权 MA** | `scripts/kernel/cbtc.py` |
| **车载 ATP** | 用 MA 反算允许速度，超速即制动 | `out.proceed(...)` 的 `speedCap` + 宿主钳位 |
| **ATS**（调度） | 决定「该不该开」「开去哪」 | `scripts/kernel/dispatch.py` |

依据：ZC 会把列车位置与区段占用做匹配，再对前方各区段逐一判断——
前方空闲就继续延伸，遇到占用就把 MA 截在障碍物前并留出安全距离
（见 [CBTC 移动授权计算](https://patents.google.com/patent/CN112678034B/en)）。
车载侧用 `v ≤ √(2·a·MA)` 把授权换算成允许速度，这是匀减速假设下的制动曲线。

**我们只做**：线性单线、按里程排序的追尾防护。
**我们不做**（见 §5）：岔区进路、折返、站台精确停车、车门联动。

## 2. 授权怎么算

```python
gap = ahead.odometer() - me.odometer()
gap -= (ahead.length() + me.length()) / 2.0     # 两车半长
ma  = max(0, gap - SAFETY_MARGIN)               # 再扣安全余量
```

三个点值得说明：

1. **扣两车半长**，不是扣一车全长。位置是车头，两车贴住时车头间距 = 两车半长之和。
2. **安全余量单独一个参数**（默认 8 格）。它对应现实里的「保护区段」，是最该按线路条件调的参数。
3. **没有前车时给 10000 格**，不是无穷大。无穷大参与运算会变成 NaN，
   而 NaN 传进速度钳位会让列车停在原地——这种故障看起来像「车坏了」。

## 3. 授权怎么变成速度

```python
cap = min(train.max_speed(), train.speed_for(ma))
```

`TrainFacade.speed_for(distance)` 由宿主提供（`v = √(2·a·d)`），
再与车辆自身最大速度取小：**只收紧，不放宽**。这条不变式和宿主侧的钳位是同一个原则——
内核可以要求更慢，永远不能让车比 Create 自己想开的还快。

授权低于 `MIN_MA`（2 格）直接给 `0.0`，避免「授权 0.5 格时允许速度算出来是个正数」这种荒唐结果。

## 4. 调度为什么单独一个内核

`dispatch.py` 只做一件事：授权够就放行，不够就 `hold`。

分开的理由是**职责**：

- 调度决定「该不该走」（运营）
- 移动闭塞决定「能走多远」（安全）

合在一起，任何一次运营策略调整都会碰到安全逻辑——这是这类系统最典型的失控路径。
两个内核各自可以热重载、各自可以被换掉：换调度不动安全，改安全不动调度。

> `hold` 不是「不给指令」。不给指令意味着把车交回原生逻辑，它会按自己的时刻表继续冲；
> `hold` 是明确的 `(authority=0, speedCap=0)`。

## 5. 自检（没有一个以上的真车时唯一的证据）

`cbtc.py` 在加载时跑 4 条断言，用假车验算：

```
[cbtc] selftest ok (4 checks)
```

| 断言 | 验什么 |
|---|---|
| `gap100 -> ma72` | 100 格间距、两车各 20 长、余量 8 → 72 |
| `too close -> 0` | 贴太近时授权归零，不是负数 |
| `no leader -> big` | 无前车时给大授权（不是无限大） |
| `curve monotonic` | 授权越大允许速度越高，且不越过车辆上限 |

> 第一次跑时第 4 条**失败了**。原因不是代码错，是我测试写错：
> 在 `max_speed=1.4` 下，10 格和 100 格都已被封顶成 1.4，`1.4 < 1.4` 自然不成立。
> 改成两个未封顶的短距离后才是有意义的断言。
> 这件事本身说明了自检的价值：它会替你发现「你以为你在验的东西」其实没验到。
